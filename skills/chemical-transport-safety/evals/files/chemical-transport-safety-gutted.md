# Dangerous Goods Classification — Sodium Hypochlorite Solution

**Prepared:** 5 July 2026. **Mode:** road, EU (ADR).

## 1. Consignment
- **Substance:** sodium hypochlorite solution (> 5% available chlorine).
- **Quantity:** 12 IBCs of 1000 L each, 12,000 L total.

## 2. Classification
The substance cross-walks to the following ADR entry:

| Field | Value |
|---|---|
| UN number | UN 1791 |
| Proper shipping name | HYPOCHLORITE SOLUTION |
| Class | Class 8 (corrosive) |
| Packing group | PG III |

The ADR classification for the road leg is UN 1791, Class 8, Packing Group III.

## 3. Packaging
The product is carried in UN-approved rigid IBCs suitable for a Class 8 PG III liquid.

## 4. Handling notes
- Drivers and handlers should wear chemical-resistant gloves and eye protection when connecting
  and disconnecting the IBCs.
- Keep the product away from acids and store upright.
- Take care to avoid spills during transfer.

## 5. Responsible person
A Dangerous Goods Safety Adviser (role) is named for the consignment.
