# Live Working Risk Assessment — Panel Fault-Finding

**Prepared:** 5 July 2026

---

## Task

Fault-finding on an energised control panel to trace an intermittent fault that only appears
when the system is running.

## Assessment

The work needs to be done live to observe the fault. The main risk is electric shock and burns. To control this, insulated tools and protective equipment are provided and the work is done by a
competent electrician.

## Controls

- Use the insulated tools and protective equipment provided.
- Keep one hand away from earthed metalwork.
- A second person is present in case of emergency.
