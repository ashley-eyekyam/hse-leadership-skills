# OSH Code Transition — Briefing Note (Delhi Factory)

**Prepared:** 5 July 2026
**Establishment:** A factory in Delhi under the Factories Act, 1948

---

## Overview

India is consolidating its labour laws into four codes. The Occupational Safety, Health and
Working Conditions Code, 2020 brings the Factories Act into a single framework alongside a
number of other statutes. The direction of travel is toward a single registration and a single
consolidated annual return in place of the separate per-law filings.

## What it means for this factory

Once the new regime is fully in effect, the establishment will register once and file one
consolidated annual return covering its safety and working-conditions obligations. The
consolidated return will replace the current annual return the factory files today.

The establishment should prepare for this transition by reviewing its current filings and
mapping them to the new consolidated structure. Delhi is expected to notify its rules in due
course. The move is expected to simplify compliance over time by reducing the number of
separate returns.

## Recommended next steps

- Review the establishment's current annual-return filing.
- Prepare to move to the consolidated return under the new framework.
- Monitor for updates on when the new regime takes effect.
